Web Technologies

HTML

HTML which stands for HyperText Markup Language, it's the standard code used to build and structure documents on the internet. It acts as the body of any website by organizing content into essential elements like paragraphs, headings, links, and images. By using special tags to label different pieces of text, HTML tells web browsers exactly how to label different pieces of text, HTML tells web browsers exatcly how to display information so that users can read and interact with web pages easily.

CSS

CSS which stands for Cascading Style Sheets. It is a standard web technology used to define the visual presentation, design, and layout of web pages. CSS acts as the design layer that dictates how that structure looks by controlling colors, fonts, spacing, alignment, and responsiveness across different device sizes.

JavaScript

JavaScript is a high-level programming language that adds dynamic behavior and interactivity to web pages. It runs directly inside web browsers to update content, respond to user actions, and modify elements without reloading the page. Modern tools like Node.js also let developers use JavaScript to build backend servers and mobile applications.

AFrame

A-Frame refers to an open-source web framework used for building virtual reality (VR) and augmented reality (AR) experiences. Its official repository on GitHub hosts the core JavaScript code, where developers collaborate to update the library and manage open-source contributions. Because A-Frame allows developers to create 3D scenes using simple HTML, its GitHub page serves as the central hub for tracking bugs, sharing documentation, and distributing the latest version of the framework.
